# 研链智证竞品研究证据库

金融投研智能体、研究平台与替代工作流的公开只读研究快照。

## 公开定位

- 这是研链智证（ChainProof）的竞品研究证据基础设施，不是第二个参赛产品。
- 首页先展示有具体竞品锚点的研究结论与产品决策，完整205项研究目录位于下方。
- 7个重点竞品拥有独立深研判断和8维横向能力矩阵，不再只是目录预设筛选。
- 数据来自发布时生成的只读快照，访问、筛选和检索仅在浏览器中完成。
- 不采集访问分析数据，不开放内部维护和判断写回。

## 本地预览

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。

## 数据边界

产品详情区分公开宣称、文档、案例、实测与待验证问题。“未找到公开证据”不等于确认某项能力不存在。公开可访问也不自动代表允许复制或商业再分发。
